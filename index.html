수집하는 정보

용어나무는 사용자의 개인정보를 수집하지 않습니다. 회원가입이나 로그인 기능이 없고, 광고나 분석 도구를 쓰지 않으며, 외부 서버로 어떤 데이터도 보내지 않습니다.

기기에 저장되는 정보

사용자가 입력한 용어, 용어 사이의 관계, 별표와 학습 기록은 사용자의 기기 안에만 저장됩니다. 개발자는 이 정보에 접근할 수 없습니다. 앱을 삭제하면 이 정보도 함께 삭제됩니다.

내보내기와 가져오기

설정의 내보내기 기능으로 만든 JSON 파일은 사용자가 직접 고른 곳(파일 앱, 메일 등)으로만 전달됩니다. 앱이 이 파일을 자동으로 어딘가에 보내지 않습니다.
